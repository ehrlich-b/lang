Locations are specified independently of compiler output. Ordinary assignments start at line 5 column 5; the nested assignment starts at line 8 column 13. diagnostic.read byte offsets [17,27) select assignment at 3:5; [34,40) select nested at 4:7; the function begins at 2:3 and the RHS has a deliberately different span at 5:8. Spanless core input has no --ast-source: its diagnostic names the AST file with no line or column (unknown location). Invalid/missing span sources must fail in core validation before numeric lowering.

A valid indirect store must preserve the enclosing fallback diagnostic context. The valid-then-global/read ordinary fixtures therefore retain the existing function location (2:1) for a later unlocated error. These expectations are fixed from the source layout and the pre-change behavior.
