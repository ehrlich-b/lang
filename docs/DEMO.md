# Make a language, run a native executable

Generated by `python3 -B test/reader_author/demo.py --case stranger`.
Only compiler, temporary workspace and temporary build paths are normalized.
The grammar edit adds optional `=`; the policy uses it. Fees are 10 below 100 and 0 at 100.
