# Direct reader handoff

The base Tariff recognizer spends its default parser work allowance before
100,000 lines. The scale comparison raises only the base recognition allowance
to 10,000,000 for the historical parser. The candidate runs with its compiled-in
defaults. The million-line base still exhausts that allowance.

Trusted native handles need the reader and backend to share a process and node
lifetime. The standalone compiler exposes that choice explicitly. Reader
workers, browser readers and AST snapshots continue to use the text protocol.

Clang can turn a copy loop into a call to the C `memcpy` symbol and use its
return value. The standard library implementation returns the destination to
match that ABI.
