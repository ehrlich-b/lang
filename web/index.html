lang▌

a self-hosted compiler-compiler — many syntaxes, one binary

lang is a compiler that compiles itself, whose real trick is readers: syntax plugins that turn any surface language into one shared AST. Five languages ride it today — a C subset, a real Lisp, a coroutine DSL, a Forth, and an indentation-delimited Python subset — composed in a single native binary, calling each other directly at the ABI level. No FFI, no VM.

Everything below was compiled to WebAssembly by lang’s LLVM backend and runs entirely in this page — view source: one small host shim, no libraries.

The polyglot tab is four languages in one wasm module: Forth answers C’s divisibility questions inside C’s trial-division loop, lang streams the primes onto a Lisp cons list, Lisp folds it, Forth folds the digits, and a Python subset — blocks delimited by nothing but the left margin — drives the whole pipeline and formats the report. (The native build has a fifth language, a coroutine DSL lowering to algebraic effects; core wasm has no stack switching yet, so it sits this page out.)

Source and devlogs: github.com/ehrlich-b/lang. Next on the roadmap: the compiler itself, compiled to wasm, compiling these languages in your browser.
